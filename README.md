# 基層神經科醫師教育活動全集

彙整台灣神經科與相關學會的**繼續教育課程／學術活動**，集中在一個頁面上，方便基層神經科醫師查詢近三個月、跨學會的課程與積分資訊。

🔗 **網站**：https://tlan1012.github.io/Taiwan_Neurology/

每週日 15:00（台北）由 GitHub Actions 自動更新；也可在 Actions 頁手動觸發。頁面提供類別、地區（北／中／南／東／線上）、來源學會三組**可複選**篩選與關鍵字搜尋，每張課程卡並附「加入 Google 行事曆」按鈕（以整日活動帶入）。

## 神經科診療指引索引

除課程彙整外，另附一個**診療指引索引頁**（[`guidelines.html`](guidelines.html)），與主頁互相連結：

- 手動策展神經科及次專科的**診療指引、治療準則與共識**，依次專科分類、可依「台灣／國際」與類別複選篩選。
- **台灣**部分連向各學會官方指引頁（腦中風、癲癇、頭痛、睡眠、動作障礙、疼痛等）。
- **國際**部分連向權威組織指引中心（AAN、EAN、AHA/ASA、ILAE、ICHD-3、MDS）；若某次專科無現成的國際學會指引頁，則改連 **PubMed** 上該領域的權威指引文獻（如 AASM、IASP NeuPSIG、EAN、NCS 等）。
- 指引不像課程每週變動，此頁為手動維護的靜態頁，不進每週自動更新流程。

## 已知限制

- **涵蓋範圍**：以各學會官網公開列表為準，只收今日起約三個月內的活動；未公開或僅限會員的課程不在其中。
- **家庭醫學醫學會**：完整課程查詢頁需圖形驗證碼，故僅抓其首頁精選的少數課程（其餘家醫課程若有申請西醫師積分，會經全聯會總表間接涵蓋）。
- **地區判讀**：依活動地點自動分類，混合實體／線上的課程歸實體區並另加線上標記；少數無法判讀者歸「其他」。可能有誤，**實際地點與積分請以主辦單位公告為準**。
- **跨來源去重**：同日期＋相似標題視為同一活動，保留學會官網版本；分類標籤取單一主類別，跨領域課程可能未涵蓋所有面向。
- **資料非官方**：本頁為自動彙整的非官方整理，僅供參考；報名與學分認定一律以各學會官方公告為準。

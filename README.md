# 基層神經科醫師教育活動全集

彙整台灣神經科與相關學會的**繼續教育課程／學術活動**，集中在一個頁面上，方便基層神經科醫師查詢近三個月、跨學會的課程與積分資訊。

🔗 **網站**：https://tlan1012.github.io/Taiwan_Neurology/

每週日 15:00（台北）由 GitHub Actions 自動更新；也可在 Actions 頁手動觸發。頁面提供類別、地區（北／中／南／東／線上）、來源學會三種篩選與關鍵字搜尋。

## 已知限制

- **涵蓋範圍**：以各學會官網公開列表為準，只收今日起約三個月內的活動；未公開或僅限會員的課程不在其中。
- **家庭醫學醫學會**：完整課程查詢頁需圖形驗證碼，故僅抓其首頁精選的少數課程（其餘家醫課程若有申請西醫師積分，會經全聯會總表間接涵蓋）。
- **地區判讀**：依活動地點自動分類，混合實體／線上的課程歸實體區並另加線上標記；少數無法判讀者歸「其他」。可能有誤，**實際地點與積分請以主辦單位公告為準**。
- **跨來源去重**：同日期＋相似標題視為同一活動，保留學會官網版本；分類標籤取單一主類別，跨領域課程可能未涵蓋所有面向。
- **資料非官方**：本頁為自動彙整的非官方整理，僅供參考；報名與學分認定一律以各學會官方公告為準。

## 授權

課程資料著作權屬各主辦學會所有；本專案僅為方便查詢之彙整工具。
